Run the app

Install Python 3.10+, extract ZIP, open terminal, then run:

py -m venv .venv
python -m pip install -r requirements.txt
python -m streamlit run app.py

Open http://localhost:8501.

Prior output discrepancy

Net P&L -67.9769 USDT and ending equity 1081.4484 USDT cannot both be correct if initial equity was 1000 USDT. This version reconciles net P&L as ending equity minus starting equity.

Currency

All accounting is USDT, not INR. ₹100,000 is not 100,000 USDT.

Live orders

Live execution is intentionally not included. This is a research prototype. Funding, liquidation, spread, partial fills and exact intraday path are not fully modeled.
